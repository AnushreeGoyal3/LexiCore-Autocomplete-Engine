# LexiCore

Trie-Based High Throughput Autocomplete Engine

## Features

- O(L) Search
- O(L) Prefix Matching
- Autocomplete Suggestions
- Dictionary Loader
- Benchmarking Suite

## Data Structures

- Trie
- DFS Traversal

## Complexity

Insert : O(L)

Search : O(L)

Autocomplete : O(L + K)

where:

L = length of prefix

K = number of returned words
